# Bonus Round — bonusroundrewards.com

A client-facing partnership presentation for the shared Scrabble and Trivial Pursuit rewards app. Includes all five approved mockups, audience fit, brand loyalty, TV Show Partners, platform proof points, and linked install/economics models.

## Preview
Unzip and open index.html. Keep all files and assets together. No installation or build is needed. You can also run npm run dev if Python 3 is installed.

## Upload and publish
Create a dedicated GitHub repository for Bonus Round. Upload the CONTENTS of this package, including assets, to the root. Do not put it in the Give It Away Games repository or overwrite that site. Connect the repository to a separate Vercel project (static site / Other, no build). Review the preview before adding bonusroundrewards.com to that project's domains. Domain registration alone does not publish this package; DNS is not changed by these files.

## Pages
- index.html: partnership presentation
- install-model.html: editable QR/social acquisition and duplicate adjustment
- economics-model.html: linked 24-month growth, partner share, gross revenue, chart, table and CSV export

## Data and assumptions
Audience inputs: 50 episodes per show (supplied by the client), Scrabble 422,000 average viewers and Trivial Pursuit 505,000 (BGE sheet). The annual planning case places those 100 episodes within one year, yielding 46,350,000 cumulative viewer exposures, not unique viewers. No reruns are added.

CW accounts: Facebook 2,200,000; Instagram 1,700,000; TikTok 1,100,000; YouTube 1,850,000; X 958,100. Sum: 7,808,100. The printed sheet total differs by 100; the model uses the platform sum. These are the same network accounts on both show cards, counted once. Followers are not unique people or measured reach.

Default response assumptions: 0.5% viewer-to-scan and 10% scan-to-install produce 23,175 QR installs. 52 shared network promotional waves/year, 3% average follower reach per platform, 1% click-through and 20% store conversion produce 24,361.272 social installs. A promotional wave assumes distribution across all listed CW accounts; this scope is not confirmed. The preset for one weekly promotion per show uses 104 waves, without doubling follower counts. Excluding 10% duplicates produces 42,782.6448 net annual installs (displayed as 42,783). These response inputs are planning assumptions, not measured show campaign results. Use sliders to change them.
Economic inputs: 45% engagement, 15% monthly churn, $5.50 gross revenue and $2.00–$2.25 partner share per active player per month. Year 2 sums months 13–24. Minimum guarantees and allocations between shows/agency are not modeled. The homepage's 200,000 sustained-player illustration ($4.8M–$5.4M annually) is separate from the acquisition model's scenario. Company proof points: $250M+ lifetime revenue and $50M+ rewards paid, supplied by Influence Mobile.

The models share scenario inputs through browser storage when available. The install-to-economics link also passes the install total directly so the scenario transfers when storage is unavailable. CSV results include assumptions. Production accounts, reward fulfillment and tracking are not part of this static presentation.
